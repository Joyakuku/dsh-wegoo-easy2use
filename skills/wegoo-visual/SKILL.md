# wegoo-visual

通过 wegoo 中继生成图像或视频。所有调用都会先弹确认卡片，用户点「确认生成」才会发上游请求；
预算闸门在确认之后、请求之前，超限直接拒绝。

## 什么时候用

- 产品设计图、演示图、demo 配图、落地页与营销素材
- Logo / 图标 / 品牌视觉元素
- 用户明确说"出图 / 画一张 / 生成视频 / 做个 logo"
- 需要把已有图片改版（换色、换背景、改风格）——这种情况用图生图

## 什么时候不要用

- 流程图、架构图、时序图：用 Mermaid 或代码画，可编辑且准确
- UI 截图、界面稿：用真实实现截图，生成的假界面会误导人
- 纯装饰性占位：CSS 渐变、几何图形、开源素材更快也更轻
- 文字排版类需求：交给文档或网页，不要用图像生成

## 流程

1. **看模型与价格**：`wegoo_models` 列出当前 key 可用的模型和单价（图像按次固定价，视频按秒）。
2. **生成**：`wegoo_image` / `wegoo_video`。工具会先弹确认卡片（含报价），用户确认后才发请求。
3. **改图**：`wegoo_image` 传 `image` 参数（本地路径、https URL 或 data URL），走图生图。
4. **回报**：把落盘路径和实际结算金额告诉用户。

## 参数要点

- 图像：`prompt`、`size`（如 1024x1024）、`n`（1-4）、`model`（留空用配置里的默认模型）
- 视频：`prompt`、`duration`、`resolution`、`model`
  - `grok-imagine-video` 是文生视频，可直接用
  - `sd2.0-*` 与 `wan3-*` 是图生视频，必须传 `image` 参考图
  - 视频按 token 计费，未校准过的「模型 + 时长」组合会拒绝报价，需先跑一次校准
- 提示词写清楚主体、材质、光线、背景、构图；想要"产品级"效果就明确写"studio light, plain background, product photo"

## 注意

- 生成结果落在插件目录的 `data/output/<日期>/` 下
- 每次花费都会进入面板右上角的结算窗口，按今日 / 本次会话 / 累计统计
